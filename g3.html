Goal 3 — Course / question signal (OpenClaw chatv2 (queue id_fb4d77))

Per-course triage + per-question psychometrics. Read the TL;DR card for the takeaway; drill into each Phase for the full tables.

What we measured

For every course we run classical test theory (CTT): per-question difficulty (fraction passing) and discrimination (point-biserial with the rest of the course). Phase D (separate page) layers in production validity using the trusted-reviewer PDR outcome from Goal 4.

What we found

Course triage in Phase A; per-question scatter in Phase B; production validity in Phase D. See the dot scatter for which questions are too easy, too hard, or anti-discriminating.

What to do

  • Look for dots in the bottom-right of the Phase B scatter (high p, low r) — those are 'everyone passes, no signal' questions.
  • Cross-check internally-strong questions against the production-validity verdict before declaring a question 'good'.
  • Phase C only runs with --with-goodness; it correlates per-question pass with each worker's downstream goodness score.
